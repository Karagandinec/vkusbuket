## Рекламная петля — как размечено (работает)

Разметка сквозная, метки живут в `session_source/medium/campaign/content` GA4
(в `landing_page` их не искать — GA4 их оттуда вырезает).

| Точка входа | source / medium | campaign | content |
|---|---|---|---|
| Meta, лента Instagram | `ig / paid` | ID кампании Meta | ID объявления |
| Meta, Facebook | `fb / paid` | ID кампании | ID объявления |
| Meta, Audience Network | `an / paid` | ID кампании | ID объявления |
| Meta, Threads | `th / paid` | ID кампании | ID объявления |
| Ссылка в шапке Instagram | `ig / social` | — | `link_in_bio` |
| Google Ads | `google / cpc` | имя кампании | автопометка |
| ChatGPT | `chatgpt.com / ai-assistant` | — | — |
| **2ГИС** | `link.2gis.ru` / `link.2gis.com` referral | — | — |

То есть: площадки Meta разделены по source, кампания и объявление проброшены
ID-шниками, ссылка в шапке помечена отдельно. **Это сделано намеренно.**

⚠️ GA4 относит `ig/fb/an/th` не в «Paid Social», а в «Paid Other» и
«Cross-network» — его дефолтный список источников их не знает. Это дефект
группировки GA4, **не** отсутствие меток. Смотреть source/medium, а не
Default channel group.

## Что действительно не связано

1. **GA4 ↔ POS.** Выручка считается в POS (`Reports.js`: `totalRev`, COGS,
   валовая/чистая прибыль, маржа, фудкост, разрезы по точкам и товарам).
   В карточке клиента (`POS.js:124`) поля источника нет: только
   `id, name, phone, discount_percent, created_at`. Все `source` в коде — это
   способ оплаты (`Expenses.js`) или локация склада (`Production.js`).
   Поэтому онлайн-канал не сводится с продажей в кассе.
2. **vkusbuket.kz** — электронная торговля в GA4 не подключена: 0 транзакций
   при ~10 тыс. сессий. Конверсии считаются как события, без денег.
3. **11 транзакций klubnikavshokolade.kz** приходят с `(not set)` источником и
   `(not set)` посадочной — похоже на серверную отправку без session-контекста.
   Само отслеживание корректно (см. ниже), теряется только атрибуция.
4. **Search Console** подключён только к `klubnikavshokolade.kz`.
   Для `vkusbuket.kz` — нет.

## Как правильно смотреть цифры

- **Meta:** MCP `mcp__Meta_ads__*`, кабинет `3522529827982603`. Только он и
  `465521244732733` отвечают на запросы.
- **Google Ads / GA4 / Search Console / Instagram:** Windsor.ai
  (`get_fields` → `get_data`). Supermetrics не авторизован ни к чему.
- **Каналы:** брать `session_source_medium`, а не `session_default_channel_group`.
- **Валюта:** расходы Meta и Google — в USD, выручка — в тенге. Курс не
  подставлять; сравнивать каналы по деньгам можно только после того, как
  появится сквозная связь с продажами.

## Открытые вопросы

- Подключить кабинет `8747974784` к Windsor — без него объём и расход
  основного Google Ads не виден.
- Погасить задолженность на `1686952041405037` и `586810819730079` —
  UNSETTLED на бизнес-аккаунте рискует блокировкой рабочего кабинета.
- Найти кабинет, которому принадлежит кампания `…0226`.
- Добавить поле источника в карточку клиента POS — это единственное, что
  замыкает петлю «реклама → продажа в кассе».
- Почистить два тестовых заказа в GA4.
